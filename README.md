# Cookie Bliss

Build a Premium Mobile-First Website for Bachelor Baabulu Cookies

Create a premium, modern, highly responsive website for a cookie brand called Bachelor Baabulu Cookies.

The website should feel like a premium boutique cookie brand, not a generic bakery website.

I have provided brand/product images that must be used in the website.

PRIMARY GOAL

Build a website that immediately communicates:

Freshly Baked • Premium Ingredients • Eggless • Made with Love

The main goal is to make visitors want to order cookies through WhatsApp.

The website should be optimized primarily for:

Mobile phones

WhatsApp users

Instagram traffic

First-time visitors

Quick product discovery

Quick ordering

The website should feel premium, warm, delicious, trustworthy, and visually impressive.

TYPOGRAPHY

Handwritten/accent font only for small decorative elements

Typography should be highly readable on mobile.

Large headings should look premium but not occupy the entire screen.

11. FLOATING WHATSAPP BUTTON

This is VERY IMPORTANT.

Create a floating WhatsApp button similar to modern food-commerce websites.

Position:

Desktop:
Bottom-right

Mobile:
Bottom-right

Use the official WhatsApp-style icon.

Button should have:

Green WhatsApp icon

Circular design

Subtle shadow

Small pulse animation

Tooltip on desktop: "Order on WhatsApp"

When clicked, open WhatsApp.

Use a configurable WhatsApp number:

WHATSAPP_NUMBER

Do NOT hard-code the number in multiple components.

Create a single configuration value.

Example logic:

https://wa.me/<WHATSAPP_NUMBER>?text=<ENCODED_MESSAGE>

For the generic floating button, message:

"Hi Bachelor Baabulu Cookies, I would like to know more about your cookies."

For product buttons, dynamically create the message based on the selected product.
